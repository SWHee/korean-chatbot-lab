# 상담 답변의 Markdown 표 렌더링

## 원인

Agent는 정상적인 Markdown 표를 반환했지만, 프론트의 작은 자체 파서는 제목·목록·문단만
지원했다. 이 때문에 `|`, `---`가 포함된 표 원문이 일반 문장처럼 노출됐다.

## 개선

- `헤더 행 + 구분 행`이 완성된 경우에만 표로 인식
- 셀 안의 굵은 글씨와 `[S1]` 근거 표기 방식 유지
- 열이 부족한 행은 빈 셀로 보정
- `<table>`, `<th>`, `<td>`를 사용한 의미 있는 HTML 구조로 출력
- 좁은 화면에서는 열을 찌그러뜨리지 않고 표 영역 안에서 가로 스크롤

범용 Markdown 패키지는 추가하지 않았다. 기존 근거 카드 연동을 유지하면서 필요한 표
문법만 `frontend/app/lib/answer-format.ts`에 확장했다.

## 확인

- 완성된 표, 부족한 셀, 스트리밍 중 미완성 표를 자동 테스트
- 데스크톱 5열 표와 375px 너비의 내부 가로 스크롤 확인
- `npm test`, `npm run build` 통과

모델이 구분 행이나 줄바꿈 자체를 누락한 잘못된 표를 생성하면 안정적으로 표로 추정하지
않고 일반 문단으로 표시한다. 이 경우에는 생성 프롬프트나 응답 구조를 수정해야 한다.
