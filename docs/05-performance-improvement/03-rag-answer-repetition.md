# RAG 답변 반복 관찰

- 작성일: 2026-07-23
- 관찰 대상: LangGraph 전환 후 A1 평가 답변

## 답변을 보고 느낀 문제

질문은 "은행이 파산하면 내 예금은 얼마까지 보호받나요?"였습니다. 검색된 top 5에
보호 한도 조문이 없자, 답변은 근거가 부족하다는 같은 결론을 여러 표현으로
반복했습니다.

```text
보호 한도에 대한 명시적 규정이 포함되어 있지 않습니다.
보호 금액의 구체적 한도는 명시되어 있지 않습니다.
법령 근거가 부족합니다.
법령 근거가 부족하여 확인할 수 없습니다.
```

읽어보니 관련성이 낮은 검색 조문도 하나씩 설명해서 질문에 필요한 내용보다 답변이
길다는 느낌을 받았습니다. 마지막에는 앞선 결론과 달리 검색 문맥에 없는 5천만원과
잘못된 조문 정보까지 추가했습니다. 이 부분은 단순히 말투가 장황한 문제가 아니라
근거 밖 사실을 생성한 문제였습니다.

## 현재 코드에서의 원인

현재 RAG prompt는 제공된 근거만 사용하고, 근거가 부족하면 확인할 수 없다고
밝히도록 되어 있습니다. 하지만 답변 길이와 형식, 결론을 몇 번 말할지, 질문과 직접
관련된 조문만 인용할지는 정하지 않았습니다.

검색 결과에 정답 근거가 없으면 모델은 질문에 답하려는 목표와 근거만 사용하라는
규칙을 동시에 처리해야 합니다. 이번 답변에서는 근거 부족을 반복하다가 마지막에
모델이 알고 있던 오래된 정보를 덧붙이는 모습이 나타났습니다.

`MAX_NEW_TOKENS=1024`는 긴 답변을 강제하는 값이 아니라 최대 생성 길이입니다. 다만
간결성 규칙이 없을 때는 반복을 계속할 여유를 줄 수 있습니다. `StrOutputParser`도
모델 문자열을 그대로 반환하기 때문에 반복 문장이나 잘못된 사실을 따로 제거하지
않습니다.

## 개선 시점

LangGraph 전환 자체를 비교하는 전체 평가까지는 기존 LangChain 기준선과 같은
prompt와 생성 설정을 유지했습니다. 구조와 prompt를 동시에 바꾸면 점수가 왜
달라졌는지 구분하기 어렵다고 생각했기 때문입니다.

이제 전환 기준선을 기록했으므로 `RAG prompt v2`를 별도 변경으로 평가해보려고
합니다. 그래프 구조와 검색 설정은 유지하고 prompt만 바꿉니다.

## Prompt v2에서 확인할 규칙

- 첫 문장에서 질문에 직접 답변
- 동일한 결론은 한 번만 작성
- 질문에 직접 관련된 조문만 인용
- 근거가 부족하면 한 번만 밝히고 외부 지식 추가 금지
- 제공된 근거에 없는 금액·조문·기관 생성 금지
- 핵심 답변, 법령 근거, 확인 한계 순서의 간결한 형식

먼저 A1 한 문항으로 반복과 5천만원 주장이 사라졌는지 확인할 예정입니다. 이후 같은
Dataset을 전체 실행해서 답변 길이, 생성 시간과 Faithfulness 변화를 비교합니다.
출력 상한은 prompt 효과를 확인한 뒤 별도 변경으로 검토하려고 합니다.
