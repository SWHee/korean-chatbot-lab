# 성능 개선 기록

이 폴더는 응답 시간뿐 아니라 검색 정확도, 답변 신뢰성, 출력 안정성처럼 사용자가
체감하는 품질을 개선 단위별로 기록한다. 아직 적용하지 않은 계획과 실제 개선 결과를
구분하고, 속도가 빨라져도 답변 품질이 낮아지면 개선으로 판단하지 않는다.

각 개선 단위는 필요한 내용만 다음 흐름으로 남긴다.

1. **관찰**: 무엇이 부족했고 어떤 실행에서 확인했는가
2. **선택**: 검토한 방법과 최종 선택의 근거는 무엇인가
3. **적용**: 코드와 실행 흐름이 어떻게 달라졌는가
4. **결과**: 같은 조건에서 무엇이 좋아지고 나빠졌는가
5. **비교·결정**: 이전과 비교해 채택할 수 있는가

| 개선 단위 | 현재 상태 | 확인된 결정 |
| --- | --- | --- |
| [`01-rag-latency`](01-rag-latency/) | 측정 설계 | 토큰 상한을 아직 변경하지 않음 |
| [`02-rag-response-reliability`](02-rag-response-reliability/) | Structured Output v2 구현 | 간결화 Prompt 후보는 미채택 |

설계 중에는 관찰·선택·적용 계획까지만 기록한다. 결과 문서는 구현과 비교 평가가
끝난 뒤에 추가한다.
