# ADR 0004. RAG corpus로 소비자보호 법령 4건을 선택한다

- 상태: Accepted
- 날짜: 2026-07-05
- 구현 상태: 수집 완료 (2026-07-06)

## 배경

RAG 단계를 시작하며 주제와 근거 문서가 필요하다. 문서 원문을 repo에
커밋해 clone만으로 인덱싱을 재현할 수 있어야 하므로, 재배포와 가공을
허용하는 라이선스가 전제 조건이다. 주제는 신입 취준생이 면접에서 직접
설명할 수 있는 난이도의 금융 도메인으로 한정했다.

주제 수준의 후보 비교와 선정 여정은 devlog
`docs/devlog/rag/topic-and-data-selection.md`에 기록했다. 이 문서는 데이터
선택의 결론만 요약한다.

## 고려한 선택지

1. KorQuAD 1.0 — CC BY-ND라 청킹·가공 결과물 재배포 불가
2. AI Hub 데이터셋 — 데이터별 이용 조건은 다르나 제3자 재배포 제한이
   공통이라 원문 동봉 불가
3. 모두의 말뭉치 — 제4유형 등 재배포 제한 다수
4. 한국은행 경제금융용어 700선 — 공공누리 표시 부재로 재배포 근거
   불명확, RAG 튜토리얼 단골 소재라 차별화 약함
5. 법령 조문 — 저작권법 제7조에 따라 저작권 비보호, 재배포·가공 가능.
   국가법령정보 공동활용 API로 구조화 XML 수집 가능

## 결정

주제를 "예·적금 이용자를 위한 소비자보호 법령 Q&A"로 정하고, corpus는
다음 4건으로 한다.

- 금융소비자 보호에 관한 법률 + 같은 법 시행령
- 예금자보호법 + 같은 법 시행령

수집은 국가법령정보 공동활용 API(open.law.go.kr)로 XML을 1회 수집해
`data/laws/`에 원문을 커밋한다. 수집 스크립트는 재현 가능하게 보존하되
정기 동기화는 만들지 않는다. 수집 시 수집일·시행일·법령 일련번호를 함께
기록해, corpus가 실시간 법률 정보가 아닌 고정 snapshot임을 명시한다.

## 결정 이유

- 법령은 원문 repo 동봉(오프라인 재현)과 공식 API 수집 파이프라인을
  동시에 만족하는 유일한 후보다.
  [저작권법 제7조](https://www.law.go.kr/법령/저작권법/제7조)가 전자를,
  [국가법령정보 공동활용 Open API](https://open.law.go.kr/LSO/openApi/openApiManual.do)가
  후자를 가능하게 한다.
- 시행령을 포함하는 이유: 예금자보호 한도 1억원(2025-09-01 시행)이
  법률이 아닌 시행령에 규정되어 있고, 설명의무의 설명사항("타 법률에
  따른 보호 여부")도 시행령에 명시되어 있다. 법률만으로는 핵심 질문에
  답할 수 없다.
- 조/항/호 구조가 표준화되어 있고 개정이 이산적(시행일 명시)이라 청킹
  단위 실험과 데이터 신선도 추적의 소재가 된다.
- 법령의 저변동성이 선정 이유이므로 1회 배치 수집이 논리적으로 일관된다.
- 역할 분업: 법령 RAG는 제도·권리 질문(보호한도, 설명의무, 청약철회
  등)을 담당하고, 상품 탐색·비교는 이후 단계의 finlife API tool 영역이다.
  finlife는 공시 데이터이므로 실시간 금리로 표현하지 않는다.
- 개별 상품의 보호 여부 판정은 공시·상품설명서 영역이므로 답하지 않고,
  법령상 보호 범위·한도 규칙 설명까지만 한다. 서비스는 "추천"이 아닌
  "정보 제공·비교"로 포지셔닝한다.

## 감수하는 단점

- 법령 문체가 초보자 대상 답변 톤과 거리가 있어 프롬프트에서 변환 부담이
  있다.
- corpus가 4건으로 작다. 청킹·임베딩 비교 실험에는 통제된 조건이지만,
  retrieval 난이도가 낮아 평가 변별력이 제한될 수 있다.
- 전자금융거래법을 제외해 전자금융 사고 관련 질문은 범위 밖이 된다.
- 상품설명서는 지금 넣지 않는다. 필요가 확인되면 원문 커밋 없이 URL과
  해시만 기록하는 방식으로 도입을 검토한다.

## 검증 계획

`docs/evaluation/rag-questions.md`의 평가 질문 24개로 검증한다. 인덱싱과
체인이 완성되면 전체 질문을 실행해 베이스라인을 기록하고, 이후 LangSmith
평가 단계의 기준선으로 사용한다. 질문에 적어 둔 조문 번호는 법령 원문
수집 후 실제 조문과 대조해 확정한다.
