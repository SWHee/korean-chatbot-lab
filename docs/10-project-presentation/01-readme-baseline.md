# 공개 README 기준선

- 갱신일: 2026-08-05

## 공개 README 범위

루트 README는 현재 사용 가능한 금융 상담 Agent의 문제, 기능, 작동 방식, 법령
데이터 출처, 실행 방법과 주의사항을 설명한다. 구현 과정이나 과거 전환 기록을
나열하지 않는다.

현재 대표 UI는 `frontend/`이며 `http://localhost:3001`에서 실행한다.
README용 히어로는 현재 UI의 네이비 배경, 근거 연결망과 포키의 색·형태를 반영한다.
영문판은 `README.en.md`에서 같은 기능 범위와 실행 방법을 제공한다.

## 개발 기록 위치

평가 기준선, Agent 평가 Dataset, 성능 실험, ADR, 수집·인덱싱 세부사항과 UI 설계
기록은 [개발 문서 허브](../README.md)에서 연결한다.

RAG 24문항 수치는 개발·회귀 기준선이며 Agent 품질의 최종 성능으로 소개하지 않는다.
Agent 평가의 실제 실행 결과가 생기면 해당 평가 문서에 먼저 조건과 함께 기록하고,
공개 README에는 검증 범위만 짧게 반영한다.
