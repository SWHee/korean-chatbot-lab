# 공개 README 기준선

## 공개 README 범위

루트 README는 현재 사용 가능한 금융 상담 Agent의 문제, 기능, 작동 방식, 법령
데이터 출처, 실행 방법과 주의사항을 설명한다. 구현 과정이나 과거 전환 기록을
나열하지 않는다.

현재 대표 UI는 `frontend/`이며 `http://localhost:3001`에서 실행한다.
README용 히어로는 현재 UI의 네이비 배경, 근거 연결망과 포키의 색·형태를 반영한다.
영문판은 `README.en.md`에서 같은 기능 범위와 실행 방법을 제공한다.

작동 방식은 공개 README와 상세 Agent 문서의 깊이를 구분한다.

- `finbom-consultation-flow.svg`: 브라우저부터 Next.js, FastAPI, Agent와 근거 반환까지의
  시스템 요청 흐름이며 공개 README에 표시
- `finbom-agent-flow.svg`: 일반 답변 경로는 세로 중앙선으로, 조건 보완·범위 안내는
  좌우 종료 분기로 구분한 Agent 흐름이며 `docs/07-langgraph-agent/README.md`에 표시

공개 README에서는 Agent 과정을 네 단계 문장으로 설명하고 상세 문서로 연결한다. 상세
그림은 실제 구현을 노드 단위로 복제하지 않고 처음 읽는 데 필요한 핵심 경로만 남긴다.

법령 검색 설명에는 현재 구현된 KURE-v1·Chroma 의미 검색과 BM25 보조 신호의 RRF
결합을 포함하되, 개발 데이터 수치를 최종 Agent 품질처럼 제시하지 않는다.

고정 Elastic IP는 공개 서비스 주소가 아니라 원본 서버 식별자다. 도메인·HTTPS와
기본적인 접근 또는 요청 제한을 갖추기 전에는 공개 README에 raw IP 링크를 직접
노출하지 않는다. 비용 관리로 서버가 상시 실행되지 않는 상태도 공개 데모 링크를
상단에 제공하지 않는 이유에 포함한다.

저장소 구조 표는 `src/`와 `scripts/` 구조 정리가 끝난 뒤 실제 경로를 기준으로 갱신한다.

## 개발 기록 위치

평가 기준선, Agent 평가 Dataset, 성능 실험, ADR, 수집·인덱싱 세부사항과 UI 설계
기록은 [개발 문서 허브](../README.md)에서 연결한다.

RAG 24문항 수치는 개발·회귀 기준선이며 Agent 품질의 최종 성능으로 소개하지 않는다.
Agent 평가의 실제 실행 결과가 생기면 해당 평가 문서에 먼저 조건과 함께 기록하고,
공개 README에는 검증 범위만 짧게 반영한다.
