# Faithfulness 점수 해석

- 작성일: 2026-07-20

Faithfulness는 RAG 답변의 사실 주장이 검색 문맥에 근거하는지 확인하는 지표다.
정답을 완전하게 말했는지나 질문에 충분히 답했는지는 별도로 평가한다.

## 세 단계 점수

| 점수 | 기준 |
| --- | --- |
| `1.0` | 핵심 사실이 모두 검색 문맥에 근거하고 모순이 없음 |
| `0.5` | 중심 내용에는 근거가 있지만 일부 부수 주장에 근거 부족이나 모순이 있음 |
| `0.0` | 중심 결론이 검색 문맥에 없거나 문맥과 명백히 모순됨 |

현재 24문항 POC에서는 세 단계만으로 판정 차이를 설명하기 충분하다. `0.7`처럼
세밀해 보이지만 기준을 설명하기 어려운 점수는 사용하지 않는다. 점수 구간을 바꾸면
이전 experiment와 직접 비교하기 어려우므로 LangChain과 LangGraph 평가에서 같은
기준을 유지한다.

## A1에서 확인한 사례

질문은 "은행이 파산하면 내 예금은 얼마까지 보호받나요?"였다. 첫 Gemini 3.5 Flash
평가에서 필요한 예금자보호법 제32조와 시행령 제18조를 검색하지 못해 검색
Precision과 Recall은 모두 `0.0`이었다.

Gemini Judge는 생성 답변이 보호 한도를 단정하지 않았다는 점을 보고 Faithfulness
`1.0`을 부여했다. 이 판정은 검색 문맥에 없는 보호 한도를 지어내지 않았다는
Faithfulness 기준에서는 타당하다. 다만 기대 답변인 1억원을 제공하지 못했으므로
검색 Recall과 질문에 대한 답변 품질은 낮다.

이 결과는 Faithfulness `1.0`이 정답성이나 전체 RAG 품질 `1.0`을 뜻하지 않는다는
사례다. 검색 품질, 근거 충실도, 질문에 대한 답변 충족도는 따로 확인해야 한다.
