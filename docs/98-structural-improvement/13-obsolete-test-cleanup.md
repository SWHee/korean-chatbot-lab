# 사용하지 않는 RAG 테스트 정리

## 문제

구조를 나눈 뒤에도 과거의 직접 실행 함수와 그 함수만 확인하는 테스트가 남아 있었다.
현재 서버와 평가는 LangGraph를 사용하므로, 이 테스트들은 실제 동작을 보호하지 못했다.

## 판단

- `run_rag_evaluation()`은 현재 평가 runner와 연결되지 않은 이전 평가 경로
- `answer_with_retrieval()`은 현재 Graph와 API에서 호출하지 않는 편의 함수
- Graph, API, 검색, 생성기, Dataset 관련 테스트는 현재 기능을 확인하므로 유지

## 적용

- 이전 평가 함수와 전용 테스트 파일 제거
- 사용하지 않는 RAG 편의 함수와 해당 테스트 한 건 제거
- 평가 문서의 실행 함수명을 현재 Graph target 기준으로 수정

## 결과

테스트가 현재 사용하는 실행 경로를 중심으로 남아, 파일 역할과 유지 이유가 더 분명해졌다.
