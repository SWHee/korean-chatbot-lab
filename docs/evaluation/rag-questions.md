# RAG 평가 질문

- 작성일: 2026-07-06
- 상태: 질문 확정, 조문 번호는 법령 원문 수집 후 대조 예정
- 용도: RAG 베이스라인 측정과 이후 LangSmith 평가의 기준 질문 세트

## 구성과 평가 기준

4개 평가 유형(A~D)과 개념형 대조군(E) 하나로 구성한다. 질문별 세부
rubric(필수 근거·금지 답변·기대 경로)은 LangSmith 평가 단계에서 확장하고,
지금은 유형별 기준만 둔다.

- 법령 근거형(A)·시행일형(B): 법령명과 조문을 인용하는지, 시행일이
  관련되면 명시하는지
- 잘못된 전제형(C): 질문의 틀린 전제를 교정하는지
- 범위 밖 상품 탐색형(D): corpus로 답할 수 없음을 고지하고 공식 확인처를
  안내하는지, 억지로 생성하지 않는지
- 개념형(E): RAG 없이도 답할 수 있는 질문에서 retrieval이 답변을
  방해하지 않는지

기대 근거의 조문 번호는 초안이다. 법령 XML 수집 후 실제 조문과 대조해
확정한다.

## A. 법령 근거형 (주력, 12개)

| # | 질문 | 기대 근거 |
| --- | --- | --- |
| A1 | 은행이 파산하면 내 예금은 얼마까지 보호받나요? | 예보법 §32, 시행령 §18 — 1억원, 2025-09-01 시행 |
| A2 | 보호 한도 1억원은 원금 기준인가요, 이자 포함인가요? | 예보법 §32 — 원금+소정이자 합산 |
| A3 | 여러 은행에 예금을 나눠 두면 각각 보호받나요? | 예보법 — 금융회사별·1인당 한도 |
| A4 | 적금도 예금자보호 대상인가요? | 예보법 §2 부보예금 정의 |
| A5 | 외화예금도 보호되나요? | 예보법 §2, 시행령 |
| A6 | 저축은행 예금도 은행과 같은 한도로 보호되나요? | 예보법 §2 부보금융회사 |
| A7 | 은행이 예금 상품을 팔 때 무엇을 설명할 의무가 있나요? | 금소법 §19, 시행령(타 법률에 따른 보호 여부 포함) |
| A8 | 금소법에서 예금은 어떤 상품 유형으로 분류되나요? | 금소법 §3 — 예금성 상품 |
| A9 | 은행이 대출을 조건으로 적금 가입을 강요하면 불법인가요? | 금소법 §20 불공정영업행위 금지 |
| A10 | 금융상품 광고에는 어떤 규제가 있나요? | 금소법 §22 |
| A11 | 설명을 제대로 못 받고 가입했다면 어떤 권리가 있나요? | 금소법 §47 위법계약해지권, §44 손해배상 |
| A12 | 예금보험료는 예금자가 내는 건가요? | 예보법 §30 — 부보금융회사 납부 |

주의: A4~A6은 상품 유형의 일반 원칙 설명과 함께 "개별 상품의 보호 여부는
공시·상품설명서 확인 필요" 안내를 포함해야 정답으로 본다. A11은 권리가
자동 성립하지 않으므로 적용 조건(법 위반 존재, 행사기간 등) 언급 여부도
본다.

## D. 범위 밖 — 상품 탐색형 (4개)

out-of-scope 마커. tool이 없는 현재 단계에서 한계를 고지하는지 확인하고,
LangGraph 단계에서 before/after 비교에 사용한다.

| # | 질문 | 기대 동작 |
| --- | --- | --- |
| D1 | 지금 금리 제일 높은 적금 알려주세요 | 법령 corpus로 답 불가 고지, 억지 생성 금지 |
| D2 | 제 상황에 맞는 예금 추천해 주세요 | 개인화 추천은 현재 corpus·tool 범위 밖임을 고지(법적 금지가 아닌 범위 한계) + 금융상품 비교공시 안내 |
| D3 | ○○은행 △△적금이 예금자보호 되는지 확인해 주세요 | 개별 상품 판정 불가, 상품설명서·공시 확인 안내 |
| D4 | 주택청약종합저축 조건이 어떻게 되나요? | 범위 밖(주택공급규칙 영역) 고지 — C1의 금소법 청약철회와는 별개 제도 |

오히려 방해되지 않는지 확인한다.
