# 적응형 상담과 근거 연결망 설계

## 목표

- 상담 전의 불필요한 오른쪽 공백을 없애고, 질문 전송 후에는 근거 패널이 나타날 자리를
  미리 안정적으로 확보한다.
- `#0B1220` 배경을 Hero부터 Chat까지 유지하면서 근거가 연결되는 과정을 하나의 배경
  언어로 보여 준다.
- 원본 레퍼런스의 둥근 비율, 높이 든 인사 손과 말풍선 배지를 살린 캐릭터로 교체한다.

## 상담 상태

- `welcome`: 질문 전. 대화 영역을 전체 폭으로 표시한다.
- `searching`: 질문 전송 후. 2열로 바꾸고 오른쪽에 현재의 쉬운 안내 문장을 표시한다.
- `evidence`: 근거 도착 후. 같은 오른쪽 영역을 실제 근거 카드로 교체한다.
- `answer`: 근거가 없는 답변 또는 오류. 빈 패널을 남기지 않고 전체 폭으로 표시한다.
- 1000px 이하에서는 상태와 무관하게 기존 단일 열을 유지한다.

## Evidence Constellation

- 후면의 고정 조명과 저대비 격자는 유지한다.
- 페이지 뒤에 한 개의 고정 SVG를 두고 점, 연결선, 문서 윤곽을 세 층으로 구성한다.
- Hero에서는 흩어진 상태, 소개 중간에서는 연결, 마지막에서는 하나의 경로로 수렴한다.
- Chat에서는 최종 상태를 낮은 투명도로 정지시켜 읽기와 입력을 방해하지 않는다.
- 색상 보간, WebGL, 새 모션 의존성은 사용하지 않는다.
- 모바일과 `prefers-reduced-motion`에서는 축약된 정적 상태를 사용한다.

## 캐릭터

- 원본 얼굴, 몸통 비율, 안테나와 둥근 손 인사 실루엣을 우선 보존한다.
- 아이보리 외장, 네이비 화면과 청록 눈·입을 사용한다.
- 가슴 말풍선과 점 세 개를 유지하고 귀 안쪽 링, 얕은 목 이음선, 손목 밴드만 더한다.
- 히어로와 상담 프로필은 같은 투명 PNG를 공유한다.

## 확인 기준

- 질문 전에는 빈 근거 열이 없고, 전송 직후 답변이 시작되기 전에 2열이 준비된다.
- 실제 근거가 도착해도 대화 열의 폭과 위치가 다시 크게 바뀌지 않는다.
- 배경색은 모든 구간에서 동일하며 장식이 밝은 상담 작업면을 침범하지 않는다.
- 375px, 768px, 1280px과 모션 최소화 환경에서 핵심 정보와 입력이 유지된다.
