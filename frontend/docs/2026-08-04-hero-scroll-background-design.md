# 히어로·스크롤·배경 개선 설계

## 목표

- 첫 화면 오른쪽 공백에 금융안심 로봇을 배치해 서비스 인상을 강화
- 소개 장면의 변화량을 휠 이동량에 맞춰 느긋하게 조정
- 단일 네이비 배경을 유지하면서 정적인 빛과 패턴으로 깊이 보완

## 설계

- 히어로는 데스크톱 2열로 구성하고 문구는 왼쪽, 로봇 상반신은 오른쪽에 배치한다.
- 모바일에서는 문구 아래에 로봇을 축소해 세로 흐름을 유지한다.
- 로봇은 레퍼런스의 친근한 인상을 유지하되 네이비·아이보리·청록으로 재해석한다.
  동일한 투명 PNG를 히어로와 상담 답변 프로필에서 함께 사용한다.
- 스토리 구간은 420vh로 늘려 단계당 약 한 화면의 체류 시간을 확보한다. 기본 스크롤과
  sticky 구조는 유지하며 스크롤 입력을 가로채지 않는다.
- 페이지 배경색은 바꾸지 않는다. 고정된 방사형 조명과 저대비 격자를 배경 전체에 한 번만
  적용하고, 섹션별 색 전환이나 움직이는 그라디언트는 사용하지 않는다.

## 보존 사항

- 채팅 API, 스트리밍, 자동 스크롤, 입력 동작과 근거 패널 계약은 변경하지 않는다.
- `prefers-reduced-motion`과 모바일에서는 기존 일반 문서 흐름을 유지한다.
- 새 프론트엔드 의존성을 추가하지 않는다.

## 확인 기준

- 375px, 768px, 1280px에서 히어로와 상담 진입이 겹치지 않는다.
- 소개 세 단계가 이전보다 급하게 넘어가지 않고 배경은 한 톤으로 이어진다.
- 로봇이 히어로와 답변 프로필에서 같은 캐릭터로 인식된다.
- 테스트와 `npm run build`가 통과한다.
