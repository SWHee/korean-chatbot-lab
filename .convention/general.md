# Finbom 코드 리뷰 기준

## API와 외부 호출

- 공개 FastAPI 경로를 추가하거나 제거하면 관련 엔드포인트 계약 테스트를 함께 수정한다.
- 외부 API와 LLM 호출에는 호출 목적에 맞는 타임아웃을 명시한다.
- 사용자 응답에는 내부 예외 메시지, API 키, 설정값을 포함하지 않는다.

## 테스트와 주석

- 동작 변경이나 버그 수정에는 해당 동작을 확인하는 테스트를 함께 추가한다.
- 실제 외부 API를 호출하는 테스트는 만들지 않고, 응답을 고정해 검증한다.
- 주석은 코드의 동작보다 선택 이유와 예외 상황을 설명한다.
